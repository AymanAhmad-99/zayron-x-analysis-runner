# Master Intelligence Engine

The engine keeps source observations separate from ZAYRON-X interpretation. Processing is deterministic: observations resolve to a canonical vulnerability entity, field observations become provenance-bearing evidence, evidence becomes typed claims, claims are corroborated or marked conflicted, and a dossier is produced with explicit unknowns and publication readiness.

`CONFIRMED_FACT` is reserved for facts supported by the evidence model. Source statements remain `SOURCE_DERIVED`; analytical conclusions are labeled `ANALYTICAL_ASSESSMENT`. Telegram and Radar are contextual signals and cannot independently establish exploitation or attribution.

Repeated observations use stable IDs derived from source, artifact, external identity, and claim content. Conflicting values produce an open conflict and `HOLD` readiness. Revision identity changes only when the analytical state changes; prior dossiers remain immutable records for persistence.

The production Worker remains health-only with `SOURCE_ACTIVATION_ENABLED=false`; no source data is collected and no public report is published in this phase.
