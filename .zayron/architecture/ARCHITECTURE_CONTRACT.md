# ZAYRON-X Architecture Contract

## Canonical Infrastructure
This contract mandates that there shall only be:
- ONE canonical frontend
- ONE canonical web Worker
- ONE canonical public domain owner
- ONE canonical API
- ONE canonical ingestion path
- ONE canonical Telegram collector
- ONE canonical production database
- ONE canonical Vectorize index
- ONE canonical queue
- ONE canonical AI runtime.

Accidental duplicates are explicitly prohibited.
