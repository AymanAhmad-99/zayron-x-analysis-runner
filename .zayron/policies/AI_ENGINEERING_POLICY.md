# ZAYRON-X AI Engineering Policy

## Rules
- AI-generated code is NOT proof.
- AI-generated architecture is NOT approved architecture.
- AI-generated test claims are NOT test results.
- AI-generated metrics are NOT production metrics.

## AI must:
- inspect
- plan
- implement
- test
- verify
- report

## AI may not:
- invent
- silently refactor architecture
- delete uncertain files
- claim unexecuted tests
- claim unverified production state
